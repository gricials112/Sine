# Sine — 交互设计方案 (Interaction Design)

> 阶段四 · 现代拟真 (Modern Skeuomorphic) 工业风。对标 Teenage Engineering + Logic Pro。

---

## 1. 设计语言 (Design Language)
- **色板**：底色 `#1A1B1E` 磨砂深空灰；面板 `#26282C` 拉丝金属；高光 `#3A3D42`；强调橙 `#FF6A2B` (TE 风信号橙)；轨色：Vocal=暖橙 / Drums=青 / Bass=品红 / Other=黄绿。
- **材质**：磨砂拉丝金属背景 + 高精度 AO (Ambient Occlusion) 阴影，控件有"陷入面板"的内阴影与"凸起"高光。
- **字体**：等宽数字 (SF Mono / TE 风) 显示 dB、BPM、Key、时间；标签用 SF Pro。
- **动效**：所有反馈 ≤ 120ms；推子/旋钮有惯性阻尼 + CoreHaptics 段落感。
- **可达性**：色盲友好 (轨道除颜色外有图标+文字)；动态字体；VoiceOver 标注每个控件值。

---

## 2. 信息架构 / 导航
```
启动 → 工程列表 (空态: 大"导入"按钮)
         ├─ [导入] → 来源选择 → 解码 → 待分离卡片
         ├─ 打开工程
         │     ├─ 待分离 → [开始分离] → 进度页 → 调音台
         │     └─ 已分离 → 调音台主页
         │                   ├─ 顶部: Metal FFT 波形 + 走带/时间
         │                   ├─ 中部: 4 路推子条 (Solo/Mute/音量/电平)
         │                   ├─ 底部: 变调旋钮 · 变速旋钮 · Other-EQ 入口
         │                   └─ [导出] → 勾选轨/参数/格式 → 渲染 → 完成
         └─ 工程管理 (重命名/删除/清缓存)
```

---

## 3. 关键界面规格

### 3.1 工程列表 / 空态
- 空态：居中拟真"电源键"风格大按钮 "导入音乐"，下方小字"全程本地处理，不上传云端"。
- 有工程：卡片列表 (封面/标题/时长/状态徽章: 待分离/已分离)。下拉清缓存，左滑删除/重命名。

### 3.2 导入与解码
- 来源 Action Sheet：相册 / 文件 / 从"分享"导入说明。
- 解码：环形进度 + "正在提取音频…"。异常 (无音轨/DRM/超 10min) → 居中卡片提示 + 操作按钮。

### 3.3 分离进度页 (难点一可视化)
- 中央大环形进度 (%); 下方：`已处理 3/8 块 · 预计剩余 01:12 · 神经网络引擎`。
- 文案随阶段切换："加载模型 → 分块推理 → 拼接音轨"。
- 右上 [取消] (二次确认)。底部小字提醒"请勿锁屏，处理中…"(实则后台也尽量续跑)。

### 3.4 调音台主页 (核心)
布局 (竖屏)：
```
┌──────────────────────────────┐
│  ▣ Metal FFT 波形 (顶部 1/3)  │  ← 120Hz, 随音量/频谱演变
│  ⏱ 00:42 / 03:18  ◀◀ ▶ ▶▶   │  ← 走带 + 进度刷
├──────────────────────────────┤
│  ┌──┐ ┌──┐ ┌──┐ ┌──┐         │
│  │V │ │D │ │B │ │O │  ← 4 路 │
│  │推│ │推│ │推│ │推│   推子 │
│  │子│ │子│ │子│ │子│        │
│  │▮ │ │▮ │ │▮ │ │▮ │  ← 电平│
│  S M  S M  S M  S M⚙          │  ← Solo/Mute (O 轨带 EQ ⚙)
├──────────────────────────────┤
│   ◍ Pitch     ◍ Speed   [导出]│  ← 两个拟真旋钮
└──────────────────────────────┘
```
- **推子**：实体质感、垂直滑轨；拖动有阻尼，过 0dB 刻度强反馈；旁边竖向电平条 (峰值保持)。
- **Solo (S)**：点亮橙色；多轨可同时 Solo。**Mute (M)**：点亮红色。两者按真值表联动 (见 FRD §4)。
- **走带**：进度条可拖动 seek；4 轨统一重排 (用户无感)。

### 3.5 变调 / 变速旋钮
- 旋钮拟真：旋转手势改值；**整半音/0.05x 步进有齿轮 Haptic**；中央数字显示 `+3 st` / `1.25x`。
- 双击旋钮复位 (0 st / 1.0x)。长按 Pitch 进入 cents 微调副尺 (v1.0 可选)。

### 3.6 Other-EQ 面板
- 10 段竖推子 + 频率刻度；顶部预设分段控件 (吉他/钢琴/中频削弱/自定义)。
- 实时听感；"复位"按钮回平直；切预设有过渡动画。

### 3.7 导出面板
- 4 个轨开关 (勾选要导出的轨)；开关 "套用当前混音 (音量/Speed/Key/EQ)"。
- 格式分段 (m4a / wav)；目标 (存到文件 / 存到相册 / 分享)。
- 底部 [导出] (未勾选任何轨时禁用)；渲染时环形进度 + 削波保护提示。

---

## 4. 手势与触感映射 (CoreHaptics)
| 控件 | 手势 | 触感 |
|---|---|---|
| 推子 | 垂直拖动 | 跨刻度 transient (强度随速度)；0dB 处更强 |
| 旋钮 | 旋转 | 每半音/每 0.05x 段落齿轮感 |
| Solo/Mute | 点击 | 短 tap |
| 复位 | 双击 | 双击确认轻震 |
| 导出完成 | — | 成功 success haptic |

---

## 5. 状态/反馈一致性
- 加载/处理统一用环形进度 + 等宽数字。
- 错误统一用居中卡片 (图标 + 标题 + 说明 + 主/次按钮)。
- 破坏性操作 (删除/取消分离) 二次确认。
- 全局禁用态：分离中禁用导出/编辑入口。

---

## 6. 空/错/边界态清单
- 工程列表空 / 导入无音轨 / DRM / 超时长 / 磁盘不足 / ANE 不可用 / EQ 复位 / 导出未选轨。每个都有明确视觉与文案 (见各界面)。
