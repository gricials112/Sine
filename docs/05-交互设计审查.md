# Sine — 交互设计审查与逻辑推敲

> 阶段五 · 对《04-交互设计》逐用例推敲交互逻辑，找出不合理处并反哺界面，输出最终界面调整。

---

## 1. 逐用例逻辑推敲

### IR-1 「分离中锁屏/切后台」体验矛盾
- **问题**：进度页文案"请勿锁屏"，但分离 3min 歌可能数分钟，强迫用户盯屏不合理；且 iOS 后台计算受限。
- **推敲**：CoreML 长任务在后台会被挂起。应：申请 `beginBackgroundTask` 争取时间；锁屏/退后台若被挂起，恢复时**从最近完成的 chunk 续跑**(chunk 边界天然是断点)。
- **界面调整**：去掉"请勿锁屏"恐吓文案，改为"可锁屏，回来自动继续"；进度持久化到 Project，重入工程恢复进度。

### IR-2 Solo 多选与单选心智不清
- **问题**：方案说"多轨可同时 Solo"，但多数用户对 Solo 的直觉是"单独听一个"。多 Solo 与 Mute 叠加易困惑。
- **推敲**：保留多 Solo 能力 (扒谱常需"人声+鼓"一起听)，但**给即时视觉解释**：进入 Solo 模式时，未发声轨整条推子降透明度 + 显示"已静音 (Solo 模式)"微标，让"为什么没声音"一目了然。
- **界面调整**：新增 Solo 模式的轨道暗化态 + 角标；长按 Solo 提示用法。

### IR-3 走带 seek 与"统一重排"的可感延迟
- **问题**：重排协议有 ~0.1s 启动锚点缓冲，快速来回 seek 会感觉"黏"。
- **推敲**：seek 时先**静音 20ms 做交叉淡化**再重排，听感上掩盖重排间隙；连续拖动 seek 时节流 (debounce 60ms) 只在松手时真正重排，拖动中只更新波形/时间显示。
- **界面调整**：走带拖动中显示预览时间气泡，松手才跳。

### IR-4 旋钮旋转手势在小屏误触
- **问题**：竖屏底部两个旋钮 + 导出按钮，旋转手势可能与系统边缘手势冲突。
- **推敲**：旋钮用"垂直拖动改值"替代纯旋转 (更稳、与推子一致)，旋转作为可选；数值可点击直接键入 (无障碍 + 精确)。
- **界面调整**：旋钮支持 拖动/点击输入 双模式；远离屏幕边缘 16pt 安全区。

### IR-5 导出"套用当前混音"语义模糊
- **问题**：用户可能想"导出纯净干声 (不带我调的音量/EQ)"，也可能想"导出我调好的版本"。一个开关说不清。
- **推敲**：拆成两种导出意图卡片：
  1. **原始分轨** (stem 原样，多选轨各自成文件)；
  2. **当前混音** (按调音台音量/Solo/Mute/Speed/Key/EQ 合成单文件)。
- **界面调整**：导出页顶部分段选 "分轨导出 / 混音导出"，下面再选具体轨/格式，消除歧义。

### IR-6 波形在静音/Solo 时该显示什么
- **问题**：FFT 波形取的是总输出还是各轨？Solo 时若仍显示总谱会与听感不符。
- **推敲**：波形取**主混音输出 (最终发声)**，与耳朵一致；Solo/Mute 改变发声 → 波形随之变化，形成"调一下、看得到"的正反馈。
- **界面调整**：明确波形数据源 = MainMixer tap。

### IR-7 首次进入调音台无引导
- **问题**：拟真控件多，新用户不知 Solo/EQ/旋钮用法。
- **推敲**：首次进入做一次性轻量 coach marks (推子/Solo/旋钮三处气泡)，可跳过，不打断。
- **界面调整**：新增 onboarding 蒙层 (仅首次)。

---

## 2. 反哺到界面的最终调整清单
1. 进度页文案与续跑：支持锁屏续跑，移除恐吓文案 (IR-1)。
2. Solo 模式暗化态 + 角标 + 长按提示 (IR-2)。
3. seek：拖动预览气泡 + 松手重排 + 交叉淡化 (IR-3)。
4. 旋钮：拖动/点击输入双模式 + 边缘安全区 (IR-4)。
5. 导出：分段 "分轨导出 / 混音导出" (IR-5)。
6. 波形数据源固定为 MainMixer 输出 (IR-6)。
7. 首次 onboarding coach marks (IR-7)。
