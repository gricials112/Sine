# Sine — 功能测试报告 (阶段六)

> 阶段六 · 开发完成后的功能测试。说明环境约束、已执行的测试、结论与待真机验证项。

---

## 1. 环境约束 (诚实说明)
本次开发与测试在 **Linux 容器** 完成，**无 Xcode / Swift 工具链**，因此：
- ✅ **核心算法**可在本环境用 Python 参考实现**真实运行测试** (三大核心难点的数学等价物)。
- ⚠️ **Swift 纯逻辑**已编写等价 XCTest，需在 macOS `swift test` 运行 (已提供可运行的 SPM 包)。
- ❌ **iOS 集成** (CoreML 推理 / AVAudioEngine 播放 / Metal / CoreHaptics / 真机内存与同步) 必须在 macOS + 真机验证，本环境无法执行。

为最大化可信度，**所有可纯逻辑化的关键算法都在本环境跑通**，并与 Swift 实现保持逐函数对应。

### 关键缺陷修复 (测试驱动)
- **DEF-1 (P0)**：`test_identity_reconstruction` 暴露设计稿误用**等功率窗**做源分离 Overlap-Add，会在相关内容上 +3dB 产生接缝鼓包。**已改为线性/三角窗** (`w_out+w_in=1`)，重建误差从 0.33 降到 <1e-9，并同步修订《03-FRD审查与优化》与 Swift `OverlapAdd`。
